# Evaluating Skills

This guide explains how to run evals, grade outputs, and iterate on skills in this repository. The workflow follows the [agentskills.io eval spec](https://agentskills.io/skill-creation/evaluating-skills).

## Overview

The eval loop has four steps:

1. **Run** — Execute each test case with and without the skill
2. **Grade** — Evaluate outputs against assertions (using an LLM or human review)
3. **Aggregate** — Compute summary statistics into `benchmark.json`
4. **Iterate** — Improve the skill based on results, then repeat

## Directory Structure

Each skill with evals has a workspace directory alongside it:

```
skills/
  shapediver-viewer/          # Skill directory
    SKILL.md
    evals/
      evals.json              # Test cases + assertions (you author this)
  shapediver-viewer-workspace/  # Workspace (generated, gitignored)
    iteration-1/
      eval-cdn-slider-basic/
        with_skill/
          outputs/             # Files produced by the agent
          grading.json         # Assertion results (LLM or human writes this)
          timing.json          # Tokens and duration (optional)
        without_skill/
          outputs/
          grading.json
          timing.json
      benchmark.json           # Aggregated statistics (generated by script)
```

## Prerequisites

- Node.js installed
- No additional dependencies needed (scripts are self-contained)

## Step 1: Setup Workspace Directories

```bash
node scripts/run-evals.js setup --iteration 1
```

This creates the directory structure for all skills that have evals.

## Step 2: Generate Agent Prompts

```bash
# All skills, with_skill mode only (default)
node scripts/run-evals.js prompts --iteration 1

# Specific skill
node scripts/run-evals.js prompts --iteration 1 --skill shapediver-viewer

# Both modes (with_skill + without_skill baseline)
node scripts/run-evals.js prompts --iteration 1 --mode both
```

This prints JSON with structured prompts for each eval. Each prompt tells an agent:

- Which skill to read (or none for baseline)
- The task to perform
- Where to save outputs

### Spawning Runs

Each eval run should start with a **clean context** — no leftover state. Use one of:

- **Subagents** (recommended): Spawn a subagent for each prompt. The isolation is automatic.
- **Separate sessions**: Open a new chat session for each run.

Copy each prompt from the `prompts` output and give it to the agent. The agent reads the skill, executes the task, and saves outputs to the specified directory.

## Step 3: Check Status

```bash
node scripts/run-evals.js status --iteration 1
```

Shows which evals have outputs and grading results.

## Step 4: Grade Outputs

Grading is done by an **LLM or human reviewer** — not by the script. The script only helps you prepare and aggregate.

### Option A: LLM Grading (recommended)

```bash
node scripts/grade-evals.js prepare 1
```

This prints a JSON array of grading tasks. For each eval that has outputs but no `grading.json`, it includes:

- The eval outputs
- The assertions to check
- The expected `grading.json` format and path

Give each task to an LLM and ask it to evaluate the assertions against the outputs, then save `grading.json` at the specified path.

### Option B: Human Grading

Manually inspect outputs in each `outputs/` directory, then create `grading.json`:

```json
{
  "assertion_results": [
    {
      "text": "The assertion text from evals.json",
      "passed": true,
      "evidence": "Specific evidence from the output"
    }
  ],
  "summary": {
    "passed": 3,
    "failed": 1,
    "total": 4,
    "pass_rate": 0.75
  }
}
```

### Grading Principles

- Require **concrete evidence** for a PASS — quote or reference the output.
- Don't give the benefit of the doubt.
- Review the assertions themselves: fix those that are too easy, too hard, or unverifiable.

## Step 5: Aggregate Results

```bash
node scripts/grade-evals.js aggregate 1
```

Reads all `grading.json` files and produces `benchmark.json` per skill with:

- Pass rates (mean, stddev) per mode
- Delta between with_skill and without_skill

## Step 6: Review Report

```bash
node scripts/grade-evals.js report 1
```

Prints a human-readable summary of all graded evals with pass/fail status and evidence.

## Step 7: Iterate

After reviewing results:

1. Identify failed assertions and patterns
2. Update `SKILL.md` to address gaps
3. Run the next iteration:

```bash
node scripts/run-evals.js setup --iteration 2
node scripts/run-evals.js prompts --iteration 2
# ... spawn runs, grade, aggregate ...
node scripts/grade-evals.js aggregate 2
node scripts/grade-evals.js report 2
```

Stop when pass rates plateau or feedback is consistently empty.

## Filtering by Skill

Both scripts support `--skill` to filter by skill directory name:

```bash
node scripts/run-evals.js prompts --skill shapediver-viewer
node scripts/grade-evals.js report 1 --skill shapediver-router
```

## Adding Evals to a Skill

Edit `skills/<skill-name>/evals/evals.json`:

```json
{
  "skill_name": "my-skill",
  "evals": [
    {
      "id": 1,
      "name": "descriptive-kebab-name",
      "prompt": "A realistic user message",
      "expected_output": "What success looks like",
      "assertions": [
        "Specific, verifiable statement about the output",
        "Another checkable assertion"
      ],
      "files": []
    }
  ]
}
```

Tips:

- Start with 2-3 test cases
- Vary prompt style and complexity
- Include at least one edge case
- Write assertions after seeing first outputs
